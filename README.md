# Crashes Fix

**Home maintenance and repair services, on demand.** Flutter app, live on the App Store & Google Play.

Crashes Fix covers air conditioning, plumbing, electricity, and other malfunctions, connecting individuals and companies with a qualified, specialized team for fast and efficient repairs.

## Download

- [Google Play](https://play.google.com/store/apps/details?id=com.smartvision.crashes_fix)
- [App Store](https://apps.apple.com/us/app/crashes-fix/id6778005881)

## Built with

Flutter · Bloc state management · RESTful API · Hive · Firebase
